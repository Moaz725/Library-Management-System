# Library Management System
A simple console-based Library Management System developed using C++.

## Features
- Add new books
- Search for books by ID
- Update book information
- Remove books
- Borrow books
- Return books
- Display all books and their availability status

## Technologies Used
- C++
- Functions
- Arrays
- Loops
- Conditional Statements
- Switch Statements
- Basic Input/Output

## Project Description
This project was developed as a Programming Fundamentals mini project.
The system allows users to manage a collection of books through a simple console menu. Each book has a unique ID, title, author, and availability status.
The project was implemented using functions and arrays without using Object-Oriented Programming (OOP).

## Learning Outcomes
Through this project, I practiced:
- Working with arrays
- Creating and using functions
- Using loops and conditions
- Searching for data inside arrays
- Updating and removing data
- Handling user input
- Building a menu-driven console application
